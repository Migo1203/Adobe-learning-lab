# 在 Illustrator 中排版作品集

**问题：**一般作品集怎么在 AI 排版？

这里的 AI 指 Adobe Illustrator。下面以屏幕阅读、投递用的电子 PDF 作品集为例；如果是印刷作品集，应先确认成品尺寸、出血和印刷厂的颜色要求。

## 一、先整理内容

作品集的目标是让读者快速看懂：你做了什么、如何思考，以及最终完成了什么。可以从以下结构开始：

1. **封面**：姓名、作品集名称和方向。
2. **个人简介或目录**：简要说明个人方向、技能和项目列表。
3. **项目展示**：挑选 3—5 个有代表性的项目，每个项目可用 2—4 页介绍背景、职责、过程和成果。数量和页数按内容调整。
4. **联系方式**：留下希望对方使用的联系方式或作品链接。

每个项目只写真实发生过的工作和结果。如果缺少数据，可以用作品图、过程图及设计说明展示，不必编造数字。

## 二、推荐的基础版式

以 1920 × 1080 px 的横版画板为例，适合先做一份电脑屏幕阅读的 PDF。以下数字是起始建议，不是固定标准。坐标以画板左上角为原点，X 向右、Y 向下；框选范围按 X / Y / 宽 / 高表示。字号使用 Illustrator 的 pt 单位；默认画板标尺下 1 px 对应 1 pt（72 pt/英寸），这不等于 PDF 的导出分辨率。

| 内容 | 起始建议 |
| --- | --- |
| 画板 | 1920 × 1080 px，RGB，用于屏幕阅读 |
| 外边距 | 左右约 96 px，上下约 72 px |
| 页面标题区 | X 96 / Y 72 / 宽 1728 / 高 100 px |
| 主要作品图片区 | X 96 / Y 206 / 宽 1056 / 高 660 px |
| 文字说明区 | X 1216 / Y 206 / 宽 608 / 高 660 px |
| 标题字号 | 48—64 pt，可按字数调整 |
| 正文字号 | 22—28 pt，行距约为字号的 1.4—1.6 倍 |
| 基础颜色 | 白色背景 `#FFFFFF`、深灰文字 `#222222`；强调色可从作品本身选择 |

一个项目页可以这样组织：

```text
┌───────────────────────────────────────────────┐
│ 项目名称 / 项目类型                            │
│                                               │
│ ┌───────────────────────┐  项目背景与目标     │
│ │                       │                     │
│ │      主要作品大图      │  我的职责           │
│ │                       │                     │
│ │                       │  设计思路或成果说明 │
│ └───────────────────────┘                     │
│ 项目名称                              页码    │
└───────────────────────────────────────────────┘
```

一页尽量只讲一个重点，让作品成为视觉主体。同一项目的说明文字靠近对应图片；标题、正文和页码的对齐线、字号及间距在整份作品集中尽量保持一致。

## 三、在 Illustrator 中操作

1. **新建画板**：按 `Ctrl+N`（Mac：`Command+N`），建立 1920 × 1080 px 的横版文档，颜色模式选 RGB。可以先做一页，再复制画板。
2. **设置参考线**：按 `Ctrl+R`（Mac：`Command+R`）显示标尺，从标尺拖出参考线，确定页面边距、图片区和文字区；也可以使用“窗口 → 对齐”辅助对齐。
3. **放置图片**：选择“文件 → 置入”，放入作品图。优先使用足够清晰的原图，避免把小图过度放大。若使用链接图片，移动文件时要一并保留素材。
4. **裁切图片**：在图片上方画一个矩形，选中矩形和图片，按 `Ctrl+7`（Mac：`Command+7`）建立剪切蒙版，得到整齐的图片区。
5. **添加文字**：用文字工具写标题、项目背景、个人职责及设计说明。统一使用少量字体和字号层级，正文尽量精简。
6. **制作其他页面**：用画板工具 `Shift+O` 和“窗口 → 画板”管理画板，复用已完成的页面结构，再替换内容。检查画板顺序，通常也是 PDF 的阅读顺序。
7. **导出 PDF**：保留一份可编辑的 `.ai` 源文件，再通过“文件 → 另存为 → Adobe PDF”选择全部画板或所需范围。导出后打开 PDF，检查页序、字体、图片和裁切。

## 四、导出前检查

- **亲密性**：标题、图片和对应说明是否靠得足够近，不同项目是否有明显区分？
- **对齐**：图片边缘、标题和正文是否沿少量共同的对齐线排列？
- **重复**：标题、正文、页码和边距是否保持一致？
- **对比**：第一眼是否先看到作品，再看到必要的说明？
- 缩小到实际阅读大小检查：文字是否易读，图片是否清楚，页面是否过于拥挤？手机阅读时可减少每页文字并适当加大字号。

如果你已有具体作品或参考图，可以根据作品数量、投递岗位、阅读设备和视觉风格再调整尺寸和版式。
